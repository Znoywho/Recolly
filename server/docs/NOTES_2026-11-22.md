## Cấu hình Kaggle (mỗi lần demo)

Run All `server/notebooks/kaggle_ollama.ipynb` (GPU T4 x2, Internet On) → cell tunnel in 5 dòng → dán vào `server/.env`:
`OLLAMA_BASE_URL`, `OLLAMA_MODEL`, `ASR_BASE_URL`, `ASR_TOKEN`, `PHOWHISPER_MODEL` → `docker compose restart server voice-worker`.
Kiểm tra: `curl $ASR_BASE_URL/health`. **Không commit notebook còn output** (chứa URL + token).

## Xem log (Dozzle)

`docker compose up -d` → mở http://localhost:8888 → chọn container:
- `recolly-server-container`: request, Sign-in, Schedule, GCal, `Ollama … ok` / `ASR via … ok` (tunnel sống) hoặc `unreachable` (Kaggle tắt).
- `recolly-voice-worker-container`: `Voice run: {...}` mỗi phút.
- `recolly-reminders-container`: `Push sent …`, `Reminders run: {...}`.
- `recolly-tunnel-container`: URL webhook (khi bật `--profile tunnel`).
Lọc bằng ô search (`WARNING`, `ERROR`, `user:<id>`). Dozzle hiện mọi container trên máy: tắt container khác trước khi chiếu.
